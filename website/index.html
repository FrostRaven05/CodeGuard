A FEW THINGS TO KNOW

开始之前，
你可能想知道。

阅读完整使用说明
CodeGuard 适合谁？

适合在 Windows 上使用 Git、经常与 AI 编码助手协作的个人开发者。你可以在提交前理解改动、核对潜在问题，也可以直接用它完成日常 Git 操作。

需要准备什么？

Windows x64 和已加入 PATH 的系统 Git。使用发布的程序不需要安装 Node.js；使用 AI 功能时，需要自行配置兼容 Chat Completions 的模型服务，费用由对应服务收取。

代码会发送到哪里？

Git 操作通过本机 Git 执行。使用 AI 功能时，所选范围内的差异与必要上下文会发送到你配置的模型服务，并遵守文件排除、敏感内容检查与预算限制。请按仓库要求选择服务和发送范围。

它会自动修复代码，或替我提交吗？

CodeGuard 解释和评审改动，不修改源码。发现可以复制给编码助手处理。提交由你点击执行，推送与分支操作按界面预览和确认执行，评审发现不会阻止你提交。

当前版本有哪些边界？

当前支持本地改动理解和本次提交评审。历史提交与分支差异评审、手动检查命令、克隆仓库、按行暂存和内置冲突编辑器尚未实现。冲突可在外部工具解决后回到工作台继续处理。
