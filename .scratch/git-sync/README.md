# 远端同步与分支操作

[任务与验收](issues/01-sync-and-branches.md) · [实现取舍](../../docs/adr/0004-explicit-git-operations.md)

[远程仓库管理](issues/02-remote-management.md)：仓库菜单内查看、添加、编辑获取/推送地址并确认删除；无远端的同步窗口可进入添加。保存后刷新同步选项，不执行网络请求；全局/引入配置与多地址显式展示并保留。

远程管理交付后完整测试 62/62、类型检查、生产构建和隔离桌面检查通过。实际界面走通添加、修改、恢复默认推送、删除取消/确认以及重复名称错误保留输入；截图和验证细节见该任务。

入口保持紧凑：顶部获取、拉取、推送；当前分支菜单内提供已有本地分支的切换、本地或远端跟踪分支的合并。预览与确认使用同一面板，提交和文件详情可折叠。1080 宽度收起刷新、仓库和模型按钮的文字，保留图标提示及同步操作文字。

获取更新远端跟踪引用；拉取预览先获取所选分支，执行固定提交的 ff-only 更新。分叉需单独确认合并，拉取和合并前要求干净工作区。普通推送以固定提交和明确 refs/heads 目标执行；无上游不猜目标，可明确选择建立上游。切换保留 Git 的覆盖检查，不自动 stash。

合并冲突保留现场并显示冲突文件，支持外部解决并暂存后的继续和预览中止；这些操作均与暂存/提交共享仓库队列。源引用、当前分支、HEAD、索引、工作区版本、合并元数据及远端配置变化会使预览失效。推送还核对远端目标是否变化。外部程序和 Git 钩子的并发不能被完全消除，执行后使用实际状态刷新；不自动回滚或删除锁文件。

验证全部使用专用临时仓库、临时裸远端、克隆和本机 HTTP 401/503 服务。没有连接用户项目远端，也没有调用真实模型。普通推送保留 pre-push 钩子；merge/commit 保留钩子与签名配置；未验证真实托管服务的登录流程。

最终生产构建与类型检查通过；完整自动测试 57/57 通过，其中同步/分支新增 12 项；隔离桌面完整检查通过。

实际桌面检查走通工具栏获取 → 拉取 → 推送 → 分支菜单切换 → 显式合并，并核对裸远端提交与本地双父合并提交。检查中修复了切换完成后仍短暂显示旧分支的问题。原有模型设置、生成提交信息和评审链路继续通过。
