# 01 — 远端同步、分支切换与合并

**What to build:** 顶栏提供获取、拉取、推送；分支菜单提供切换和合并。单个面板预览目标、提交和文件后执行，失败保留工作与草稿。

**Blocked by:** 无，依赖已完成的 Git 工作台。

**Status:** done

- [x] 操作统一进入仓库写队列，执行前验证预览、引用、配置与工作状态。
- [x] 显式远端和目标普通推送；获取不改工作区；拉取只快进，分叉转显式合并。
- [x] 本地分支安全切换；合并显示来源、目标与分歧，冲突列表、外部处理后继续/中止。
- [x] 无上游、无远端、游离 HEAD、锁、钩子/认证/网络错误及过期预览有可理解反馈。
- [x] 临时裸远端与克隆验证完整链路，检查 IPC、桌面入口及紧凑布局，不对用户仓库试写或联网。
