# 03 — 新建分支与远端检出

**What to build:** 顶部分支菜单支持新建并切换本地分支、获取新分支、检出远端分支为本地跟踪分支，并能继续拉取。checkout 不等同于合并远端到当前分支。

**Blocked by:** 01-sync-and-branches.md（done）。

**Status:** done

- [x] 预览固定来源、目标名称、上游和文件差异，确认后执行。
- [x] 名称、同名分支、来源变动、工作区覆盖及锁由业务接口与 Git 检查，不覆盖分支或自动 stash。
- [x] 远端新分支可获取、检出并随后快进拉取，兼容显式远端选择。
- [x] 使用临时裸远端和工作仓库验证，保留用户真实暂存区与配置。
