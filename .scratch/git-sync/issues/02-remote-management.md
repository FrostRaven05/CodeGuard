# 02 — 远程仓库管理

**What to build:** 仓库菜单提供远程仓库管理窗口，查看、添加、修改获取/推送地址及确认删除，保存后刷新同步选项。

**Blocked by:** 01-sync-and-branches.md（done）。

**Status:** done

- [x] 支持空状态、添加、编辑、删除确认与错误反馈；无远端的同步窗口可进入管理。
- [x] 使用真实 Git、本地配置和仓库写队列；校验名称、地址、重复项及外部配置变化，不发起网络请求。
