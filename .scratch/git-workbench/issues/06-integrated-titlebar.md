**What to build:** 移除突兀的浅色系统标题栏，将标题区域融入现有深色顶栏，保留 Windows 原生窗口控制与拖动行为。

**Blocked by:** 无。

**Status:** done

- [x] 桌面只保留一条深色顶栏，品牌、仓库、分支与操作保持清晰。
- [x] 原生最小化、最大化/还原、关闭保留；空白区域可拖动，控件可正常点击。
- [x] 使用系统提供的标题安全区域，最小窗口宽度下不遮挡工具栏。
- [x] 类型检查、生产构建和隔离桌面验证通过；重新启动最新应用。

参考：[Electron 自定义标题栏](https://www.electronjs.org/docs/latest/tutorial/custom-title-bar)。仅调整桌面窗口与布局，不增加执行接口，浏览器预览保持原布局。
