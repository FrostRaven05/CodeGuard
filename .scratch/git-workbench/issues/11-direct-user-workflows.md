- 发起评审即进入可视化审查，结果就地展示；仍能返回提交准备。
- 侧栏可直接管理远程仓库，从同步进入管理后可明确继续原操作。
- Git 索引缓存刷新不误报草稿过期，真正暂存/分支变化仍被识别。
- 临时仓库测试通过，不修改用户仓库的暂存区。
