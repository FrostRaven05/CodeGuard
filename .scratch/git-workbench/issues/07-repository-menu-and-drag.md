# 07 — 深色仓库菜单与明确的标题拖动区

**What to build:** 将原生 select 替换为与工作台一致的深色仓库菜单，顶栏中央空白区明确用于拖动窗口，交互控件保持可点击。

**Blocked by:** 06（done）。

**Status:** done

- [x] 仓库菜单有深色浮层、当前项与路径提示，支持鼠标、键盘、Esc 及外部点击收起。
- [x] 中央空白区域有明确拖动元素，不遮挡仓库与工具按钮。
- [x] Windows 原生命中检查确认空白区域返回 HTCAPTION，仓库和工具按钮返回 HTCLIENT。
- [x] 两种窗口宽度、菜单切换、类型检查、构建与隔离桌面集成通过；重启最新应用。

## Evidence

2026-10-18：先对现有临时测试窗口执行 Windows WM_NCHITTEST。1080 与 1440 宽度下，中央空白点均返回 2（HTCAPTION），工具按钮均返回 1（HTCLIENT）。未复现空白点不可拖动；后续将新增明确的空白区域并对多点及仓库按钮检查，避免只依据 CSS 属性判断。

完成：仓库 select 改为 portal 深色菜单，展示路径、当前项对勾、键盘高亮；浮层独立于标题拖动区域。增加中央弹性拖动元素。1080 与 1440 宽度下，各三处中央采样点均返回 HTCAPTION，仓库按钮与工具按钮均返回 HTCLIENT。此验证只读查询专用测试窗口，不移动鼠标或操作用户窗口。

实际沙箱渲染进程验证两专用临时仓库间的方向键+Enter 切换、鼠标切回、Esc 收起、外部 pointerdown 收起和当前项；原有密钥、评审、提交与历史集成仍通过。类型检查和生产构建通过。已查看 `.local/repository-menu-preview.png` 的展开菜单视觉效果（截图使用专用临时仓库，不包含用户源码或模型配置）；捕获时短暂显示不抢焦点的测试窗口以获得真实绘制，捕获后关闭。
