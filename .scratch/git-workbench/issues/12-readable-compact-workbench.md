# 12 · 大字与简洁首屏

- Status: done
- Blockers: none
- Scope: 放大文字、精简标题和小字信息，右侧常用提交及评审操作无需滚动可见。

## 验收

- 主要文字和按钮使用 14px，辅助信息至少 12px；窄窗口不通过缩小字体挤入。
- 右栏加宽，移除重复分支卡、仓库状态和常驻说明，缩短提交编辑区。
- 暂存计数、生成说明、预览提交、评审及结果入口在 1080×700 和 1440×950 首屏可见。
- 规范与需求按需展开，按钮保持在展开内容之前；详情在可视化主区查看。
- 移除重复导航、装饰标题及底部重复统计，保留关键的范围、过期、失败、部分覆盖和检查未运行提示。
- 构建及隔离桌面流程通过，实际检查大小窗口布局。不修改用户暂存区。

## 验证

- `npm run build` 通过，类型检查及生产构建完成。
- `npm run test:desktop` 最终通过：1080×700 和 1440×950 均断言右栏无溢出滚动、文字输入 14px、宽度至少 330px，生成、预览提交、评审和结果按钮完整处于首屏；展开规范与需求后主要按钮仍可见。
- 隔离桌面流程继续覆盖模型设置、评审与行为/流程/风险卡片、代码定位与过期、生成草稿与人工编辑/取消、远程管理、暂存全部、真实提交与历史、同步和分支操作。
- 检视两种尺寸实际截图，正文与文件名放大、右栏留白充分、无重复导航/分支卡/仓库状态/草稿常驻小字。截图：`.local/compact-check/workbench-1080.png`、`workbench-1440.png`（临时仓库）。
- 未更改 Git 业务逻辑，验证均在独立临时仓库；用户暂存区保持原样。
