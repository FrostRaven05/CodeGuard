# CodeGuard

Before changing product behavior, read `CONTEXT.md` and the relevant section of `docs/product-plan.md`. For architecture changes, read applicable decisions in `docs/adr/`.

Git write verification uses disposable repositories. Keep the user's working directory and staging area intact during development checks.

## Agent skills

### Triage labels

Use the default triage vocabulary in `docs/agents/triage-labels.md` when classifying work.

### Domain docs

This is a single-context project. Read `docs/agents/domain.md` when updating domain language or recording an architecture decision.
