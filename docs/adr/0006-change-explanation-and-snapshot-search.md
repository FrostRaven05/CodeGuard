# 改动图解与固定快照搜索核对

2026-11-12。扩展 ADR-0003 的有限附近上下文，沿用 ADR-0005 的本地/暂存范围隔离。

结果入口改为“改动图解”，首先呈现行为前后对比及影响流程，再展示简短假设、实际搜索证据、结论与建议。假设是面向用户、可核实的行为陈述，不展示或保存供应商内部推理。

一次任务最多两个模型请求。首次请求使用固定差异、附近上下文和用户依据，提出最多四个带差异锚点的假设及字面符号。服务校验锚点与摘录后，在相同新/旧树中跨目录搜索，再将受预算约束的真实命中片段交给第二次请求形成最终图解与结论。不执行模型生成的搜索命令、正则或项目代码，不自动重试。旧兼容服务未返回有效假设时，仍可保存原有结果，但界面明确没有搜索核对记录。

扫描候选覆盖支持的源码扩展名（TS/JS、Python、Rust、Go、C/C++ 等），不局限同目录。读取固定树普通文件，不跟随链接或子模块，沿用路径排除、重命名排除和内容密钥检测。两个版本合计最多扫描 300 个源码文件、约 150 万字符；每个假设最多保留八处片段、每文件每版本最多两处。给搜索证据预留共同上下文预算；发送前再次核对总量。扫描和读取之间检查取消，取消或任一请求失败保留旧结果。界面记录实际扫描数、候选数、未读数、截断和适用范围；未命中不能当作不存在。

第二轮结论只接受该假设真实搜索命中的对应路径、版本侧、行号与整行摘录；无有效引用时降为待确认，并丢弃未经证据支持的结论文本。代码摘录匹配只证明引用有效，不证明语义判断正确，因此支持/反证均注明静态核对，检查继续显示未运行。发现仍定位到所选差异，不将未改文件的上下文冒充新增问题。

最近结果一并保存图解、假设、命中片段、结论及扫描限制；新增字段可选以兼容旧记录。两个请求的用量合计，缺少任一部分保持未知。左侧按 Git 状态分组的文件树负责改动导航及暂存，结果页移除重复文件导航，仅保留文件筛选和快照差异入口。
