# 全部本地改动理解、人工处置与连续浏览

2026-10-25。扩展 ADR-0002、ADR-0003 的固定版本评审，保留原有本次提交语义。

全部本地改动从 HEAD 到当前工作区生成独立快照，包括 Git 未忽略的未跟踪文件。读取前检查路径及每级链接，不跟随符号链接、目录链接或子模块；限制大小、二进制、敏感路径、内容与共同预算。读取时关闭仓库配置的 clean/process 过滤器，临时索引命令使用空钩子目录。普通文件按原始字节经 `hash-object --no-filters` 固定到对象库，再在应用目录创建的独立索引上构造树；不改变真实索引或工作文件。独立索引及目录在 finally 中检查所属位置后清理。可能生成不可达 Git 对象，与现有暂存树快照一致由 Git 管理；不自动运行回收或清理用户对象。

原始工作区字节不等于 clean filter 或行尾转换后的暂存内容，界面始终称工作区快照。被排除的删除仍参与重命名识别，重命名后的差异沿用源路径排除，不能通过改名进入模型上下文。当前 HEAD、分支及所选本地文件的内容摘要绑定版本；发送前重读核对，结果按相同语义识别过期。排除内容只记录路径及原因，不发送；相关上下文从相同不可变树读取。模型仍不能运行代码、修改 Git 或决定人工验收。

应用存储为本次提交保留原 latest 字段，并单独存储 localLatest；旧记录可继续读取。两种范围分别保留人工处置。评审发现的位置链接读取该结果的固定树，避免用索引到工作区的增量差异冒充 HEAD 到工作区的完整改动。本地理解从不构成本次提交已评审的证据，提交预览独立读取提交范围的结果。

规范/需求草稿由仓库级前端存储持有，按输入顺序持久化；组件卸载不取消排队保存。旧服务器响应不覆盖较新的输入；失败保留草稿，显示重试。准备评审等待保存完成。人工处置同样按发现排队保存。

处置由应用单独存储，不接受模型提供的状态。采用路径、版本侧、维度、标题、代码整行证据的摘要保守关联；行号不是身份。匹配不确定时保留独立问题，避免继承错误的忽略/处理决定。后续结果保存此前未再发现的记录并注明本轮是否覆盖该文件；人工处置、模型复查与实际检查证据分别表达，不把任何一种替代另两种。

历史保留原只读接口以兼容既有调用，新增分页查询。游标为已扫描位置，搜索标题、作者和哈希覆盖尚未加载的历史；分支引用必须属于仓库现有 refs，文本查询不拼接 shell。界面忽略旧查询响应、去重加载并明确是否还有更多；左侧浏览不改变检出分支。
