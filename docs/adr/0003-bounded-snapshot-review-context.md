# 固定版本的有限文本上下文与模型验证

2026-10-18。沿用 ADR-0002 的暂存评审、系统密钥和提醒式评审语义。

必要上下文从评审固定的暂存树和 HEAD 对象读取，删除行使用 HEAD；不读取工作区、不跟随链接、不递归进入子模块。先发送差异，剩余预算中最多使用总预算的三分之一补充 TS/JS、Python 的函数附近和文本引用、测试片段。每文件最多考虑前 12 个改动位置，每段最多 120 行；每个版本只扫描同目录源码及测试候选的前 40 个文件，每文件最多 3 处引用。没有识别到函数或超出扫描范围时不推断完整关系。其他语言仍可评审差异，明确提示未关联上下文。

这是无执行的启发式文本关联，不是语义调用图。发送预览展示来源路径、版本对象、行范围、大小与未纳入原因。差异和上下文共用排除规则、疑似密钥检测与总字符预算，规范和需求也检查敏感内容与排除引用；结果过滤排除路径，疑似密钥结果不保存。位置与连续整行摘录仍只在已发送差异中核对，不能证明缺陷真实成立。所有相关内容取自同一个暂存树，因此现有树/HEAD/分支指纹覆盖上下文变化，未暂存修改不会使结果过期。

真实模型验证独立于日常工作台，通过 Electron 运行时只读复用用户配置和系统密钥。默认只检查公开配置，显式 `--run` 后最多请求 4 次且不重试，只发送合成样例的临时 Git 快照。请求失败即停止，协议和位置统计与人工语义判定分开，保留实际返回用量；缺少用量或价格保持未知。模型返回格式无效时也保留已收到的用量指标，不把失败当成免费或漏报。验证报告放在忽略版本控制的 `.local/model-validation/`，不将密钥、响应头或服务错误原文写入报告。

没有可用配置时完成流程和自动测试，真实服务质量保持待验证。以上机制不参与 Git 提交条件，也不运行项目文档中的命令或自动修复代码。
