# Issue tracker: Local Markdown

Issues live in `.scratch/<feature>/issues/<NN>-<slug>.md`, one file per ticket, numbered in dependency order. Each ticket declares its blocking tickets, end-to-end behavior, acceptance criteria, and status.

Use `ready-for-agent` for specified work, `in-progress` while implementing, and `done` only when the acceptance criteria are verified. Record verification evidence in the same ticket. A ticket can start when every blocker is done. This project uses no external issue tracker.
